# Livecheck landing page

Static landing page for Livecheck: launch checks, fixes and monthly care for AI-built sites.

## Files
- `index.html` – the whole page (HTML + inline styles, no build step)
- `assets/chris.jpg` – About section photo
- `assets/Livecheck-Launch-Checklist.pdf` – free checklist download

## Before going live
- **Intake form:** posts to Formspree (form `xljjoprr`). Submissions arrive in the Formspree inbox and by email.
- **Offers:** £49 Site Check (entry, credited against any paid job), Fix My Site £295, Go Live £400 (£600 with database and logins), Code Health Report £500. Monthly Care £100/mo is a follow-on after a paid job. Every button scrolls to the intake form.
- **Placeholders:** search `index.html` for `[` to find remaining ones (stats source, client rescues).

## Hosting
Served by GitHub Pages from the `main` branch root (Settings → Pages).
